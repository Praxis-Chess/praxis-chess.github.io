01Sync

Every game from your Chess.com archives, month by month, skipping months already fetched. You choose which speeds get analysed; rapid by default.

02Evaluate

A quick Stockfish pass over every position, then a deeper search with three candidate lines on each flagged move.

03Flag

The drop in winning chances sets the severity: inaccuracy, mistake or blunder. Arithmetic, with the clock reading attached. No model is asked.

04Verify

Each mistake gets an evidence graph of engine facts. Hand-written rules name the cause, and a checker passes every claim before it is marked verified.

05Explain

A local model writes the reason for the top three mistakes per game by default. It is handed the engine's verdict, never asked for one.

06Aggregate

Mistakes become patterns and drills from your own games. The pattern summary is written by the local model from those counts.

05 / Evidence

A claim needs
a fact behind it.

Language models write fluent chess nonsense. So Praxis computes the facts first, from the board and the engine, and checks what a model says against them. Ask Prax, the assistant, answers questions about your games only from what its tools return, and says so when they return nothing.

Facts are computed from the board and the engine first. What a model says is checked against them.

07 / Where it runs

On your
machine.
By default.

The engine, the models and the database are processes on your computer. No account, no upload, nothing to cancel. Two optional features reach out, and both stay off until you switch them on: web research for general chess questions, and a cloud model provider.

Every part of it is a process on your computer. Web research and cloud models are optional and off by default.

09 / InstallGet Praxis

Three commands.
Docker does the rest.

No Java, Node or chess engine to install. Docker builds Praxis with Stockfish 19 inside, downloads the models, and serves it on this computer only. No account: open it and enter your Chess.com username.

Praxis runs on a computer, with Docker. Send yourself the link and set it up there. No account; only your Chess.com username.

  1. 01Install Docker Desktop
  2. 02Clone the repository
  3. 03docker compose -f docker/compose.yaml up -d --build
  4. 04Open localhost:8086, enter your username

8.5 GB of models // 3.8 GB light

Does any of my data leave the machine? +

Not by default. The only outbound requests are to the public Chess.com archive for games under your own username, and the one-time model downloads. No account, no telemetry. Web research and a cloud model provider are optional, off until you configure them, and a cloud provider receives the positions it is asked about.

Do I need a GPU? +

It helps. With an NVIDIA card, add the GPU file shown under Windows · Linux. Docker on a Mac cannot use the GPU, so on a Mac the models run in Ollama installed natively. Without a GPU the models run on the CPU, which works but is much slower; Stockfish always runs on the CPU.

How do I back up my games? +

One command writes a database dump to a backups folder: docker compose -f docker/compose.yaml run --rm backup. The install guide covers restoring, upgrading and uninstalling.

First: install Ollama from ollama.com and start it.

  1. git clone https://github.com/Praxis-Chess/Praxis-Chess.git
  2. cd Praxis-Chess
  3. docker compose -f docker/compose.yaml -f docker/compose.gpu.yaml up -d --build

Light set: copy docker/.env.example to docker/.env and uncomment its two light-set lines first.
